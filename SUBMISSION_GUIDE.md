# Submission Guide

## Before you submit

- [ ] Add your own portrait as `images/profile.jpg`.
- [ ] Open `index.html` in a browser and check the page from top to bottom.
- [ ] Test the navigation links on both desktop and mobile widths.
- [ ] Click each GitHub and LinkedIn link to confirm it opens your profile.
- [ ] Confirm your email address and academic details are correct.
- [ ] Review each project repository and make sure the titles/descriptions represent your work accurately.
- [ ] Push the complete folder to a GitHub repository named `portfolio-website`.
- [ ] Add the deployed website URL if you publish it with GitHub Pages.

## AI tools used

ChatGPT was used as an AI coding assistant to help plan the page structure, generate a first version of the HTML/CSS/JavaScript, improve responsive styling, and review accessibility and code organisation. The code was then reviewed and adjusted for the student's details and assignment requirements.

## Example prompts used during development

1. "Act as a senior front-end developer. Plan a clean, responsive personal portfolio for a Level 2 Software Engineering student in Cameroon using only HTML, CSS and vanilla JavaScript."
2. "Write semantic HTML for a personal portfolio with Home, About, Skills, Projects and Contact sections. Include accessible navigation and a dedicated profile-photo area."
3. "Create a polished mobile-first CSS design for the portfolio. Use a professional editorial style, clear typography, responsive layouts and visible keyboard focus states."
4. "Review the JavaScript and website structure for errors, accessibility and responsive behaviour. Keep the code beginner-friendly and explain how to test it."

## Assignment requirements checklist

- [x] Homepage with name and introduction
- [x] About section

- [x] Projects section
- [x] Contact section
- [x] HTML, CSS and JavaScript
- [x] Responsive desktop and mobile layouts

- [x] Review and correction of generated code

## Important

A local website opened from `index.html` is not yet a live website. Publish the repository with GitHub Pages (or another static hosting service) to obtain a public live URL. Add that URL to your submission after deployment.
